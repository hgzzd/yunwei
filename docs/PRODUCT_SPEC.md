# 云尾兽产品规格

## 产品定位

云尾兽是 Windows 10/11 x64 上的本地优先、低打扰陪伴型桌面宠物。它应像桌面边缘一个有节奏感的生命，而不是待办、监控、聊天或高频小游戏入口。

### 固定约束

1. 技术栈固定为 Tauri 2、Rust 2021、TypeScript 5、Vite 6、Canvas 2D、`tauri-plugin-autostart` 与 `tauri-plugin-single-instance`。
2. Rust 是高层行为、权威位置、落脚点、Windows 环境信息及设置的唯一决定者。
3. TypeScript/Canvas 只承担显示协议已授权的动作、逐帧动画、微动作、输入采样和气泡呈现；不得自行决定高层行为、迁移目标或落脚点。
4. 宠物窗口 `pet` 与气泡窗口 `bubble` 是两个独立、透明、小型窗口；禁止全屏透明覆盖层。
5. 无账号、无云端业务、无遥测；设置和运行数据保留在本机。
6. 产品开发以 M1–M4 的完整里程碑为单位。里程碑内可分模块和提交，但不得抽取成脱离里程碑验收的小任务。
7. 每个实现模块默认 TDD；无法自动化的 Windows 交互必须把规则下沉到可测核心，再补充原生 Windows 手工验收。

## 体验原则

| 原则 | 产品含义 | 工程约束 |
| --- | --- | --- |
| 低打扰 | 不抢焦点、不遮挡工作、不高频出声或说话 | 气泡与随机行为必须有频率、去重和冷却；系统环境优先级高于宠物显示 |
| 陪伴感 | 动作应有起因、过程和落点，而非随机闪变 | 高层计划由 Rust 给出，Canvas 只连续呈现该计划 |
| 可预期 | 拖动、尺寸、位置和显示模式符合用户意图 | 坐标、设置和窗口模式由 Rust 权威化并可恢复 |
| 可恢复 | 显示器、前台窗口或应用异常变化不能让宠物丢失 | 每项平台策略都有回退点、默认值和安全位置恢复 |
| 本地优先 | 核心能力在断网时可用 | 不设计网络协议、账户、远端配置或遥测 |

## 已明确的产品能力边界

- 允许：自然待机、移动、跳跃/落地、拖拽、低频互动与气泡、Windows 环境避让、托盘和设置。
- 不在本轮规格中增加：任务管理、效率工具、聊天机器人、联网内容、排行榜、成就系统、多人同步、全屏交互层或高频游戏化玩法。
- 未在本文或里程碑中明确的行为规则必须先取得产品确认，不能由实现方补充为“更聪明”的功能。

## 里程碑结果

| 里程碑 | 对用户的完成感 | 前置条件 |
| --- | --- | --- |
| M1 自然地活着 | 宠物会自然待机、行走、完整跳跃、落地和受控拖拽，动作连续且有落点 | 无 |
| M2 生活在 Windows 里 | 宠物能正确理解多屏、DPI、前台窗口、全屏和显示器断开 | M1 的权威坐标、运动计划和落脚点 |
| M3 成为有性格的朋友 | 宠物能理解低频互动和活动状态，用独立气泡进行克制回应 | M1 行为协议；M2 环境状态 |
| M4 产品化收尾 | 用户可稳定配置、恢复、开机启动、单实例运行、排错和安装验收 | M1–M3 的协议稳定 |

## 成功标准

产品完成不是“状态枚举存在”，而是：用户在真实 Windows 桌面上感到宠物自然、不妨碍工作、能够恢复且长期稳定。自动化测试证明规则，Windows 手工验收证明窗口、DPI、前台窗口与安装包行为。
